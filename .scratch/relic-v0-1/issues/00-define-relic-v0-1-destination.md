## Question

What exact product journey, scope boundary, privacy posture, performance contract, and completion proof define Relic v0.1?

## Comments

### Resolution — 2026-08-15

Relic v0.1 carries execution through a working macOS/Linux MVP. It imports native zsh/Bash history, metadata-only shell hooks, Git, Prime Agent traces, and Claude Code traces; performs offline local search plus model-backed bounded RLM recall; emits exact citations and honest evidence grades; runs only explicit approved validation; compiles and manually activates a content-addressed Agent Skill; and proves that a held-out second task selects the exact skill before broad archaeology with improved calls/tokens/time and no loss of verified success.

The CLI remains complete and JSON-scriptable; a focused TUI is also required. SQLite FTS5 narrows the corpus before optional `fzf`. Redaction precedes persistence and model egress. Performance budgets in the map are hard acceptance gates. Codex subscription authentication is research-gated and non-blocking. `harnessd` is a separate project and outside this map.
